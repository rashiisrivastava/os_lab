# Operating System Virtual Lab

A web-based virtual lab designed to simulate and visualize core Operating System algorithms interactively. This project helps students understand OS concepts through real-time execution and graphical visualization of algorithms.

---

## Features

- Interactive Operating System algorithm simulations
- Step-by-step execution visualization
- Beginner-friendly UI
- Real-time scheduling and memory management simulations
- Educational project for learning OS concepts practically

---

## Algorithms Implemented

### CPU Scheduling
- First Come First Serve (FCFS)
- Shortest Job First (SJF)
- Priority Scheduling
- Round Robin Scheduling

### Page Replacement
- FIFO
- LRU
- Optimal Page Replacement

### Memory Management
- Paging
- Memory Allocation Techniques

### Deadlock Handling
- Banker's Algorithm
- Deadlock Detection

---

## Learning Outcomes

- Understanding Operating System algorithms
- Practical implementation of scheduling techniques
- Memory management concepts
- Deadlock handling and prevention
- JavaScript-based algorithm visualization
